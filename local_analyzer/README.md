# SmartTrade AI — מחקר והשוואה מקומיים

יישום Python בעברית למחקר מניות. ללא שירות בתשלום, מפתחות API או חיבור לפרודקשן.
נדרש Python 3.10 ומעלה; Node אינו נדרש להפעלת היישום.

מתיקיית המאגר:

```powershell
python local_analyzer/server.py
```

פתח http://127.0.0.1:8765 והשאר את השרת פועל. ב־Windows אפשר גם להפעיל `Start.cmd`.
נתוני המשתמש נשמרים ב־`local_analyzer/data/research.sqlite3`, המוחרג מ־Git.
הקבצים `research/model.mjs` ו־`research/research.css` נדרשים לצד תיקיית היישום.

## שימוש

1. לחץ **עדכן דירוג אוטומטי** לשליפת TOP 20 בארה״ב לפי שווי שוק. CompaniesMarketCap
   מוצלב מול StockAnalysis, כולל השלמת Berkshire מדף החברה. הרכב וסדר חייבים להתאים.
2. בחר חברה ושלוף נתונים יומיים ונתונים מדוחות באמצעות שני הכפתורים הנפרדים.
3. פתח **דירוג והשוואת TOP 20**. אפשר למיין, לסנן ולבחור עד ארבע חברות להשוואה.
   החישוב מתבסס על המטמון בלבד ואינו מפעיל שליפה קבוצתית של 20 חברות.
4. חברה ללא נתונים מספקים נשארת בטבלה ללא ציון מלא. כיסוי הנתונים מוצג במפורש.

מחירי סוף יום מגיעים מממשק ציבורי לא רשמי של Yahoo Finance. דוחות מגיעים מסדרות Yahoo
ומטבלאות StockAnalysis. מוצגים מקור, תקופה, זמן שליפה, חוסרים ומחלוקות בין הספקים.
החיבור אינו מבטיח זמינות או זמן אמת. אין עקיפת חסימות או החלפה בנתונים מומצאים.
כשל בעדכון אינו מוחק מטמון תקין. המגבלה המקומית היא 8 בקשות מקור לדקה; שליפת דוחות
או דירוג צורכת עד ארבע בקשות ומוגבלת לפעם בחמש דקות לאותו סוג/סימול.

## נוסחת ההשוואה

הציון הטכני הקיים משתמש ב־MA20/50/100/200, MACD ו־RSI. מחושבים גם ADX, ATR ו־Bollinger.
הציון הפונדמנטלי משתמש בחמישה רכיבים **שנתיים** במשקל 20 כל אחד: שולי רווח נקי
0–30%, שולי רווח תפעולי 0–40%, צמיחת הכנסות שנתית ‎−10–30%, תזרים חופשי/הכנסות
0–25%, וחוב/הון 2–0 (נמוך עדיף). כל טווח ממופה ליניארית ונחתך ל־0–20.
נדרשים כל חמשת הרכיבים; אפס הוא ערך תקין ואינו חוסר. הון לא חיובי או מחלוקת ספקים
ברכיב מונעים ציון מלא. אין השלמת נתונים מתקופות אחרות או חלוקה מחדש של המשקולות.

הציון המשולב הוא 50% טכני ו־50% פונדמנטלי. נדרשים מחיר עד שבעה ימים, דוח שנתי עד
550 יום ועותק דוחות שנשלף בשבעת הימים האחרונים. המקום בדירוג ניתן רק לחברות בעלות
ציון מלא ואותו יום מחירים. שווי השוק קובע את רשימת החברות, ואינו רכיב בציון.
השוואת חברות מענפים שונים מוגבלת; אין התאמה ענפית. הספים ניסיוניים, אינם מודל חיזוי,
תמחור הוגן או המלצת השקעה. הדירוג הוא בין החברות עם כיסוי מלא, ולא בהכרח כל העשרים.

תאריך מדידת שווי השוק המדויק אינו מסופק; זמן השליפה אינו תחליף לו. תאריכי Yahoo
עשויים להיות מנורמלים לסוף חודש. מועד הגשת הדוח אינו זמין, ולכן זה אינו מאגר לבדיקות
עבר המבוססות על מה שהיה ידוע בזמן אמת. אין ערבוב עם צילום ניתוח טכני היסטורי שנבחר בגרף.

## בדיקות מבודדות

```powershell
python -m unittest discover -s local_analyzer/tests -v
cd local_analyzer
npm.cmd install
npx.cmd playwright install chromium
npm.cmd run test:browser
```

בדיקות הדפדפן מפעילות שני שרתים מקומיים עם נתונים סינתטיים מסומנים ומסדי בדיקה
נפרדים, ללא פנייה לספקי מידע. גרסת הפיתוח נבדקה עם 55 בדיקות Python ו־15 בדיקות Chromium.
שליפת מידע אמיתי ל־NVDA ול־AAPL נבדקה בנפרד ב־25.11.2026; ארבעה נתוני כותרת של NVDA
תאמו להודעת החברה ברמת העיגול שפורסמה. אין בכך אישור לכל השדות והחברות.

ענף זה מיועד לפיתוח מקומי. אין לשנות הגדרות Cloudflare, להפעיל פריסה או למזג לפרודקשן
כחלק מהתקנת היישום.
